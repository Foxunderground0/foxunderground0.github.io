Smart Braille Gloves

A wearable Braille keyboard that sends touch input to a computer over Bluetooth.

2021CompletedHardware

Bluetooth · Accessibility · Touch sensing · Python

View code on GitHub

Motivation

The project creates a compact text input path for users who communicate through Braille.

Implementation and scope

  • Mapped touch sensor combinations to Braille characters.
  • Sent decoded input over Bluetooth.
  • Built a Python receiver that entered the characters as keyboard input.

Outputs

  • Produced a working wearable input prototype for Teknofest.
