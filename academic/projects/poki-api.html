Image Emotion API

A pipeline that collects images, removes duplicates, classifies facial emotion, and serves results through an API.

2023CompletedSoftware

Python · Computer vision · Node.js · API

View code on GitHub

Motivation

The project links data collection, cleanup, model inference, and delivery into one usable pipeline.

Implementation and scope

  • Collected images and removed duplicates with SHA 256 hashes.
  • Detected faces and classified emotion with a convolutional model.
  • Served processed images through a Node.js API.

Outputs

  • Produced an end to end data and inference service.
